# ESP32 智能小车

> 🏫 谷山学校智能小车项目  
> 制作人：任芊羽

基于 ESP32-S3 的 WiFi 遥控智能小车，支持手动控制、超声波避障、自动巡线三种模式。

---

## 一、硬件清单

| 组件 | 型号/规格 | 数量 |
|------|----------|:----:|
| 主控板 | 4D Systems GEN4-ESP32 16MB (ESP32S3-R8N16) | 1 |
| 电机驱动 | L298N | 1 |
| 直流电机 | 四驱车用减速电机 | 4 |
| 巡线传感器 | 8 路红外巡线模块（用中间 4 路） | 1 |
| 超声波 | HC-SR04 | 1 |
| 电池/电源 | 12V 输入 + 底板 5V/3.3V | 1 |
| 车架 | 四驱车底盘 | 1 |

## 二、技术架构

```
┌─────────────────────────────────────────────────┐
│                  iPad / 浏览器                     │
│          http://192.168.4.1 (WiFi AP)            │
└────────────────────┬────────────────────────────┘
                     │ HTTP GET
                     ▼
┌─────────────────────────────────────────────────┐
│              ESP32-S3 Web 服务器                   │
│                                                   │
│  / → HTML 控制页面（响应式，手机+iPad适配）        │
│  /action?cmd= → 电机控制（forward/backward/...）   │
│  /sensors → 巡线传感器 JSON 数据                  │
│  /distance → 超声波距离 + 状态 + 倒计时            │
│  /line_action?cmd= → 巡线模式控制                  │
└───────────┬───────────────────┬──────────────────┘
            │                   │
            ▼                   ▼
┌──────────────────┐  ┌──────────────────────┐
│   L298N 电机驱动   │  │   HC-SR04 超声波      │
│  GPIO15-18 PWM   │  │   Trig=GPIO8         │
│  前进/后退/转向    │  │   Echo=GPIO9         │
└──────────────────┘  └──────────────────────┘
            │
            ▼
┌──────────────────┐
│  巡线传感器        │
│  GPIO4-7         │
│  OUT3~OUT6       │
└──────────────────┘
```

### 软件架构

```
main.cpp
├── 初始化 (setup)
│   ├── PWM 通道 (ledc, 5kHz, 8bit)
│   ├── GPIO 引脚模式设置
│   ├── WiFi AP (ESP32-Car / 12345678)
│   └── Web 路由注册
│
├── 主循环 (loop)
│   ├── server.handleClient()    ← 处理 HTTP 请求
│   ├── 安全状态机 (每 30ms)
│   │   ├── 巡线模式 → 传感器偏差修正转向
│   │   ├── 撤离状态 → 1 秒后停止
│   │   ├── 自动模式 → 5 秒后停止 + 避障检测
│   │   └── 手动后退 → 实时避障检测
│   └── 串口日志输出 (每 500ms)
│
└── 状态变量
    ├── currentCmd: stop / forward / backward / ...
    ├── lineFollowing: true / false
    └── motorSpeed: 153 (默认 60%)
```

## 三、三种使用场景

### 🎮 场景一：手动控制

- **适用**：自由驾驶、功能调试
- **操作**：手机/iPad 浏览器打开控制页
- 单击方向键 → 持续移动
- 再次单击同方向或按 STOP → 停止
- 支持键盘 **WASD** / **方向键**

### 🛡️ 场景二：超声波避障

- **适用**：倒车防撞、自动保护
- 传感器安装在 **车尾**，朝后测距
- 后退遇障碍物 < **20cm** → 自动停止 → 前进 1 秒撤离
- 避障卡片按钮：点击后跑 **5 秒**自动停
- loop() 每 30ms 安全兜底检测

### 🚗 场景三：巡线模式

- **适用**：沿黑线自动驾驶
- 4 路传感器检测偏差 → 自动转向修正
- 慢速行驶（约 40% PWM），稳定可靠
- 走到线末端（全白）→ 自动停止
- 点击手动方向键或避障按钮自动退出巡线

## 五、构建与烧录

```bash
# 编译
pio run -e 4d_systems_esp32s3_gen4_r8n16

# 上传（替换端口号）
pio run --target upload --upload-port /dev/cu.usbmodem2101

# 串口监视
pio device monitor -p /dev/cu.usbmodem2101 -b 115200
```

## 八、Web API 接口

| 路由 | 方法 | 参数 | 说明 |
|------|:----:|------|------|
| `/` | GET | — | 返回 HTML 控制页面 |
| `/action` | GET | `cmd=forward/backward/left/right/stop` | 电机控制 |
| `/action` | GET | `cmd=auto_forward/auto_backward/auto_stop` | 避障模式 |
| `/sensors` | GET | — | 返回 `[true,false,true,false]` |
| `/distance` | GET | — | 返回 `{"distance":12.3, "cmd":"stop", "remaining":0}` |
| `/line_action` | GET | `cmd=start/stop` | 巡线模式控制 |
